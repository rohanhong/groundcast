# Assets

| Folder | Contents |
| --- | --- |
| [`brand/`](brand/README.md) | The brand kit: the mark, wordmark, lockups, and social preview, all drawn by `src/groundcast/icon.py`. See its README for the guide. |

The two are kept apart so a demo can be re-recorded or replaced without
touching the brand kit, which a test keeps identical to the drawing.
